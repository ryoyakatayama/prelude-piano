# Prélude · ピアノ練習室

iPad / Safariで使う、端末内保存に対応したピアノ練習PWAです。GitHub Pagesに静的ファイルだけを公開します。データベース、APIサーバー、APIキー、CDN、アカウント登録は不要です。

公開URL: [Préludeを開く](https://ryoyakatayama.github.io/prelude-piano/)

## 使い始める

1. 公開URLの「アプリをインストール」を押します。iPad / iPhoneはSafariの共有 →「ホーム画面に追加」→「追加」。対応するChrome / Edgeではインストール画面が開きます。端末別の案内とURLコピーは「使い方・設定」からも利用できます。
2. ライブラリの「パスワードを入力」で共通パスワードを入力します。自分の端末では「この端末で覚える」を選べます。
3. 曲ごとの「端末に保存」を押します。
4. 「オフライン準備完了」の表示を確認します。
5. 「練習する」から再生。A・Bには開始小節と終了小節を指定します。B小節は最後まで再生します。
6. iPadの音量も確認してください。バックグラウンドに移ると再生とマイクを停止します。

「端末から削除」はその曲の端末データだけを消し、GitHubの原本を残します。再ダウンロード可能です。GitHubにない端末だけの曲や編集は、削除前にバックアップしてください。

音が出ない場合は「使い方・設定」→「音を確認（ド・ミ・ソ）」で音声を再接続できます。iPad本体の音量、Bluetooth / AirPlayの出力先も確認してください。Audio Session API対応環境では音楽再生用の出力を選び、アプリ復帰時は音声を作り直します。旧iPadOSでは消音モードの解除が必要な場合があります。アプリ内の音量はドラッグ中に1%刻みで反映し、音量変化を滑らかにつなぎます。

## 共通パスワードと複数端末

iPad・PC・スマートフォンで同じ公開URLを開き、同じパスワードを入力します。8文字以上（数字8桁も可）に対応しています。アプリと曲一覧は公開され、写真・音符・WAVの内容は暗号化されています。

「この端末で覚える」はパスワードそのものではなく、そのライブラリ用の復号鍵を端末に保存します。「入力の記憶を解除」で解除できます。ダウンロード済みの曲は解除後もオフラインで使用できます。保存曲・練習位置・テンポ・編集内容は端末ごとです。別端末への移動にはバックアップを利用できます。通常のバックアップとWAV書き出しは暗号化されず、GitHub追加用の暗号化書き出しとは用途が異なります。

設定したパスワードはGitHubやチャットに保存されません。忘れると新しい端末で復号できないため、控えを保管してください。暗号方式と初期設定の説明は[SECURITY.md](SECURITY.md)を参照してください。

## 機能

- 検索可能な曲一覧、「すべて / 保存済み」の切り替え、保存容量の目安
- 曲単位のダウンロード / 端末から削除 / 原本更新の取得
- 写真の複数ページ読み込みと表示、音符データからの簡易五線譜表示
- 写真上・五線譜上の再生カーソル、小節タップでシーク
- 楽譜上のA・Bつまみをタッチでドラッグするリピート設定（小節単位、段・ページ間の自動スクロール）
- A–B小節リピート、20〜300 BPM、両手 / 右手 / 左手再生
- 合成ピアノ音源、メトロノーム、4拍カウント、音量、拡大、自動スクロール
- ドレミ / 運指の表示切り替え、音符・運指・写真上の位置の編集
- マイクによる単音追従（試験機能）。マイク音声は端末内処理のみ
- 曲データ / WAV書き出し、曲と設定をまとめるバックアップ / 復元
- スコアと練習設定: IndexedDB。アプリ本体: Service Workerキャッシュ
- 検索除外: HTML `noindex, nofollow, noarchive`

## 写真 → このチャット → GitHub → アプリ

写真をこのチャットに送り、次のように依頼してください。

> Prélude用に読み取ってください。音符・休符・リズム・左右の手・運指を確認し、元の写真と小節の位置を含む .piano.json を作成してください。ryoyakatayama/prelude-piano の公開鍵で曲と音源を暗号化して追加してください。

1. 写真を目視で読み、音程・拍・長さ・運指を構造化します。曖昧な箇所は確認し、推測を確定情報として登録しません。
2. [FORMAT.md](FORMAT.md)に従う `.piano.json` を作成します。写真はJPEG / PNG / WebPのdata URLとして含めます。
3. 採譜用データは公開リポジトリ外の作業フォルダーに保存します。
4. `node scripts/protect.mjs <作業フォルダー>` で音源生成・暗号化し、`node scripts/prepare.mjs` で一覧とオフライン版を生成します。公開鍵を使うため、曲追加にパスワードを渡す必要はありません。
5. テスト・チェック後、mainにpushするとGitHub Pagesが更新されます。
6. アプリの「一覧を更新」→新曲を「端末に保存」。既存曲の更新は更新アイコンで取得します。

写真だけの読み込みは閲覧用です。ブラウザ単独で写真から音符を自動認識するOMRは搭載していません。音符の構造化はこのチャットで行うか、アプリ内の編集画面で手入力します。端末で編集した内容のGitHubへの自動アップロードも行いません。曲データを書き出して、このチャットで更新を依頼できます。

## 音源と追従の対応範囲

練習音源はWeb Audioで音符情報から生成する合成ピアノ音です。録音されたグランドピアノのサンプル音源ではありません。GitHubにも生成したWAVを暗号化して保存しますが、アプリ内再生はテンポ・片手変更のため音符から合成します。このため大きいWAVを端末に保存する必要はありません。

マイク追従は単一の基本周波数を検出し、現在地の近く4イベントを照合します。両手選択時は右手を追います。和音全体の認識、精密な採点、複雑な両手演奏の追跡は未対応です。ペダル、連打、残響、周囲の音でずれる場合は小節をタップして位置を合わせ直してください。実機のiPadと生ピアノでの精度は別途確認が必要です。

簡易五線譜は音程、休符、音価、左右の手、運指を表示します。出版用の完全な譜刻エンジンではなく、異名同音はシャープ系に正規化します。連符・複雑な声部・装飾・強弱記号などの正確な原本表示には写真モードを使用してください。曲データの時間軸は展開済みの演奏順序で記述します。

## 公開・検索除外・端末保存

HTMLのnoindexは検索エンジンへの依頼であり、閲覧制限ではありません。公開GitHubリポジトリ内の暗号化ファイルや曲一覧、公開URLは参照可能です。初回公開時のサンプル2曲は以前から公開されており、過去のGit履歴とサンプル生成コードにも残ります。新しく追加する楽譜と音源は公開前に暗号化します。プロジェクトPagesでは `robots.txt` をドメインルートに配置できないため、実際の検索除外は各HTMLのmetaタグで指定します。リポジトリ自体の検索非表示は保証できません。

iPadOSはブラウザデータを削除する場合があります。「ホーム画面に追加」「保存の保持をリクエスト」を用意していますが永久保存は保証されません。端末だけの編集内容は、設定 → バックアップから「ファイル」などに保存してください。

公開サイトの更新時、新版は安全のため即時に差し替えません。「新しい版の準備ができました」と表示されたらPréludeをすべて閉じて開き直してください。保存した曲や設定は更新後も引き継ぎます。

## 開発・公開

Node.js 22以上。外部パッケージのインストールは不要です。

```sh
node scripts/serve.mjs
# http://127.0.0.1:43189/
node --test tests/*.test.mjs
node scripts/prepare.mjs
node scripts/check.mjs
```

曲を追加・変更する場合は、公開リポジトリ外に `.piano.json` を置き、`node scripts/protect.mjs <入力フォルダー>` → `node scripts/prepare.mjs` → テスト・チェックの順に実行します。公開フォルダーに平文の楽譜やWAVを残すとチェックが失敗します。

GitHubリポジトリの Settings → Pages → Source を **GitHub Actions** にすると、同梱の `.github/workflows/pages.yml` が検証と公開を実行します。依存パッケージはなく、公開対象は `docs/` だけです。手動公開を使う場合はmainの `/docs` を配信元にできます。

## ファイル構成

|場所|内容|
|---|---|
|`docs/main.js`|ライブラリと練習画面の動作|
|`docs/views.js`, `styles.css`|画面レイアウト|
|`docs/core.js`, `score.js`|データ検証、音符・小節の時間軸、表示|
|`docs/audio.js`, `follower.js`|音源とマイク追従|
|`docs/storage.js`, `dialogs.js`|端末保存、編集、インポート、バックアップ|
|`docs/tracks/*.piano.enc.json`|暗号化された曲、写真、音符、運指|
|`docs/tracks/*.wav.enc.json`|暗号化された合成練習音源|
|`docs/vault.json`, `crypto.js`, `vault.js`|公開鍵、暗号処理、パスワード入力と端末記憶|
|`docs/catalog.json`, `sw.js`|生成される一覧とオフライン設定|

サンプルの「よろこびの歌」はベートーヴェンの旋律を使う独自の簡易編曲、ウォームアップはオリジナル練習曲です。
